2サイトへの広告掲載ファイルと手順
作成日：2026年8月4日

【公開前に必ず確認】
A8.netとアクセストレードの両方で、次の2サイトが掲載サイトとして登録されていることを確認してください。

1. https://marensidejob.github.io/
2. https://marensidejob.github.io/shigoto-note/

片方しか登録していない場合は、もう片方をサイト追加して、必要な審査・提携が完了してから広告を公開してください。

----------------------------------------
1．やさしいAI副業ノート
----------------------------------------

使用するZIP：shigoto-note-upload.zip
GitHubリポジトリ：marensidejob/shigoto-note

ZIPを展開すると、次の構成になっています。

index.html
articles/a8-accesstrade-comparison.html
images/covers/a8-accesstrade-comparison.png

GitHubでのアップロード順：

1. リポジトリの articles フォルダを開く
2. Add file → Upload files
3. a8-accesstrade-comparison.html をアップロード
4. Commit changes
5. images → covers フォルダを開く
6. a8-accesstrade-comparison.png をアップロード
7. Commit changes
8. リポジトリの一番上へ戻る
9. index.html をアップロードして既存ファイルを置き換える
10. Commit changes

公開確認URL：
https://marensidejob.github.io/shigoto-note/articles/a8-accesstrade-comparison.html

トップページにも比較記事のカードが表示されます。

----------------------------------------
広告コードについて
----------------------------------------

両記事には、次の提供コードを組み込んであります。

・A8.net：テキスト広告＋1×1計測画像
・アクセストレード：300×250バナー広告

提供された広告コードのリンク、文言、計測画像は変更していません。

----------------------------------------
表示確認
----------------------------------------

GitHub Pagesへの反映には数分かかる場合があります。

公開後に次を確認してください。

・記事上部に「広告について」の表示がある
・A8.netのテキスト広告を押すとA8.netへ移動する
・アクセストレードの300×250バナーが表示される
・スマートフォンで横にはみ出さない
・自分で広告から登録して成果を発生させない
